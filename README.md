## Objetivo

O projeto demonstra o processo de planejamento visual de um dashboard analítico antes da implementação técnica.

A proposta foi estruturar uma interface clara e profissional para análise de acidentes de trânsito do DATATRAN, priorizando leitura rápida dos principais indicadores e organização das informações.

## Estrutura do dashboard

O protótipo foi organizado para apresentar uma visão executiva dos dados, incluindo:

- KPIs de acidentes, mortes, pessoas feridas e veículos envolvidos
- Evolução mensal dos acidentes
- Perfil dos acidentes
- Ranking por estados
- Principais fatores associados aos acidentes
- Tipos de via
- Filtros para segmentação das análises
- Navegação lateral entre diferentes perspectivas do dashboard

## Decisões de design

O projeto foi estruturado com foco em:

- **Hierarquia visual:** indicadores principais aparecem antes das análises detalhadas.
- **Arquitetura da informação:** agrupamento das informações por contexto e relevância.
- **Leitura rápida:** destaque para números, tendências e comparações.
- **Consistência visual:** padronização de cards, espaçamentos, tipografia, ícones e cores.
- **Usabilidade:** filtros e navegação posicionados de forma clara e previsível.
- **Storytelling analítico:** organização das visualizações para conduzir a leitura dos principais indicadores aos detalhes.
